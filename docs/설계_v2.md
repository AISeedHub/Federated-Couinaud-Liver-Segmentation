# CouinaudFL v2 설계 기록 (2026-09-02 확정)

## 목표
Radiology: AI 투고. 퀴노 9분절 분할에서 (1) 공개 벤치마크 SOTA, (2) 4기관 연합학습이 단일센터·공개 모델 zero-shot을 능가함을 보인다.
논지: 공개 데이터로 학습한 정확한 모델도 기관을 옮기면 무너진다 → 데이터를 모으지 않고 간극을 메우는 방법이 연합학습.

## 모델 (SegResNet 폐기)
- TotalSegmentator `total`(task 291) 과 동일한 nnU-Net v2 PlainConvUNet 3d_fullres: base 32, 6단계 [32,64,128,256,320,320], conv 2/단계, stride [1,2,2,2,2,2], InstanceNorm(affine), LeakyReLU, deep supervision. 31.2M 파라미터.
- 초기화: TS 291 체크포인트 292개 텐서 중 seg 헤드 10개 제외 282개 이식. MR 모델은 TS 730(`total_mr`).
- 초기화 적법성(원문 확인): TS CT 데이터 = Basel PACS 무작위(v1 1,204/v2 1,228 공개; 가중치는 1,559 — 추가분은 "GE 스캐너·타 기관" 미공개, 공개 데이터셋 언급 없음). TS MRI = Basel 576 + IDC 116 + TS CT 527. MSD/LiTS/퀴노 라벨 미포함.
- **TS 570(CT 퀴노)은 초기화 금지**: Tian 193 전체로 5-fold 학습(JIIM 2026 원문) → Lee-50·MedSeg 오염. zero-shot 비교 상대로만 사용.
- 입력: 512 원본, 패치 96×256×256(z 80 + zero-pad 16; ÷32 조건), f32 batch 1 = 13.6 GB(RTX 8000 실측) → 센터 24GB 하한 충족. AMP 7.0 GB.
- 출력: 10클래스 소프트맥스(bg + S1,S2,S3,S4a,S4b,S5–S8). 8분절 라벨은 4a+4b 확률 합산으로 부분 감독. 좌우 반전 증강 금지(키랄).

## 평가 매트릭스

## FL
- Flower 1.11. 방법: FedAvg, FedProx(mu 0.01), FedAdam(서버 Adam, lr 1e-3), FedBN-IN(InstanceNorm affine 로컬 유지 — BN 아님을 명시).
- 클라이언트는 서버가 보낸 글로벌 파라미터 스냅샷으로만 평가·최종 테스트(v1 로컬상태 버그 재발 방지). 서버 config(method/lr/epochs/fold) 준수.
- 실험별 포트: exp4c 9595(4센터), exp5c 9596(5센터). 서버는 fold×method 세션을 순차 실행, 클라이언트는 자동 재접속·DONE 마커·STOP.txt.
- 산출: 환자·분절별 Dice/HD95/부피 CSV(센터 로컬), 글로벌 가중치 라운드별 저장.

## 배포 전 검증 결과 (2026-09-03, tag v2.0-centers)
- 정식 모의시험(run_final1, exp4c 동일 설정·축소): FL 4방법론 × 2 fold, 단일센터, 글로벌 가중치 일치, 익명화·로그 포함, 재개(같은 run 재실행) → 통과. 업로드 2.88GB 수집 확인, ID 노출 0.
- 순차 실행(seq1→seq2, 서버 한 줄 + run_center_seq): 두 실험 모두 통과. 수정: 서버는 실험 종료 후 수집기를 유지(STOP_SERVER.txt로 종료).
- 강제 종료 시험(crash1): 2라운드 학습 중 클라이언트 kill -9 → 서버는 fail=1로 집계 후 진행, 40초 뒤 재시작한 클라이언트가 같은 라운드 평가부터 재합류, 3라운드 완료·DONE·테스트 산출. round_timeout_sec(기본 3h)·예외 시 모델 재생성 적용.
- 이 서버 GPU 공유로 발생한 OOM은 센터 단독 GPU(24GB, 사용 13–17GB)에서는 해당 없음.
- 미검증: Windows .bat 실제 실행(센터 PC 1대에서 install.bat·run_center.bat 확인 필요), 외부망 9595/9596/9598 접속.
